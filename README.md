# FitCoach — Smart Fitness Assistant

FitCoach is a fitness web app prototype that helps users create simple workout routines based on their goals and available time.

## Features
- Select fitness level and workout duration
- Generate workout plans for different fitness goals
- Chat-style fitness assistant interface
- Guided workout timer and exercise progression
- Responsive dark-themed interface

## Technology Stack
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Select a fitness goal and duration.
4. Create a workout plan and test the timer.

## Current Limitations
The current version uses predefined rules and responses. It does not connect to a real AI model or Amazon Alexa+.

## Purpose
FitCoach explores how a conversational fitness experience could work on a smart screen. It is an independent prototype and is not an official Amazon product.
